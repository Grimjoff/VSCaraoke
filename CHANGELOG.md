# Changelog

## 0.1.0

First release. 🎤

- Synced lyrics for whatever is playing on Spotify, via [LRCLIB](https://lrclib.net)
- Smart lyric lookup: cleans up "Remastered", "feat." and friends, falls back to search
- Manual lyric search when the automatic match is wrong (remembered per song)
- Lyrics timing nudges (earlier / later) and a global offset setting
- `instant` or `sweep` line highlighting, with word-by-word timing when available
- A pixel stage with five dancing species (plus uninvited bugs)
- Tempo from [ReccoBeats](https://reccobeats.com), or tap it yourself on the BPM label
- Album-art colors, and a click on the dance floor for random ones
- Chaos levels from `calm` to `chaos`, configurable crowd size and species
- Custom sign-in callback URL for when the default port is taken
